# 🔐 Burglar Alarm System using Arduino and PIR Sensor

A simple and low-cost security system that detects motion using a PIR sensor and triggers an alarm using a buzzer.

## 📌 Overview
This project uses an Arduino Uno and a PIR (Passive Infrared) sensor to detect human movement. When motion is detected, a buzzer is activated to alert the user.

## ⚙️ Components Used
- Arduino Uno  
- PIR Sensor  
- Buzzer  
- Jumper Wires  
- Power Supply  

## 🚀 Working
- PIR sensor detects motion (human body heat)
- Sends HIGH signal to Arduino
- Arduino activates buzzer
- Alarm turns OFF when no motion is detected

## 🔌 Applications
- Home Security  
- Office Monitoring  
- Restricted Area Surveillance  

## 💡 Features
- Low cost  
- Easy to build  
- Real-time motion detection
